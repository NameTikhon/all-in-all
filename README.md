# ALL IN ALL

Локальный помощник для **переводного Дурака, 36 карт, один на один**. Основной режим — автоматический анализ выбранного окна игры. Ручной выбор карт кликами находится в отдельном запасном режиме. Интерфейс на русском; сервер слушает только `127.0.0.1`.

## Запуск

Нужен Node.js **22 или новее**. Устанавливать библиотеки не требуется.

```powershell
cd all-in-all
node server.mjs
```

Откройте [приложение](http://127.0.0.1:8765/). Также можно запустить `start.ps1` из PowerShell. Остановка сервера: `Ctrl+C`.

## Первый запуск: автоматический анализ

1. На вкладке **«Автоматически»** нажмите **«Настройки ИИ»**.
2. Выберите **GenAPI**, оставьте модель **`gpt-6-luna`**, вставьте API-ключ в поле с паролем и нажмите **«Сохранить подключение»**. Для подключения нужен ключ именно GenAPI.
3. Нажмите **«Выбрать окно и начать»** и в системном диалоге браузера выберите окно или вкладку с игрой. Для полной памяти партии лучше начать с новой раздачи, когда открыта вся ваша рука.
4. При настроенном ключе анализ запускается автоматически после подключения окна. Карты, козырь, очередь хода и остаток начальной колоды определяются без ручного ввода. Запросы оплачиваются по тарифу вашего аккаунта. После паузы наблюдение можно продолжить кнопкой **«Начать автоанализ»**.
5. Следите за картами, счётчиками и советом. **«Пауза»** останавливает автоматические запросы, а **«Остановить»** прекращает демонстрацию окна.

Браузер должен получить разрешение на демонстрацию от пользователя. Приложение не выбирает окно без системного диалога и не нажимает карты в самой игре.

Сначала приложение локально находит светлое игровое поле **durak.hlop.de** по его цветам и расположению карт. Найденная область фиксируется на время подключения окна: только она сравнивается и передаётся модели. Изменения панели помощника, счётчика онлайна, заголовка страницы и статистики под столом не вызывают запросов. Если поле не найдено, приложение продолжает локальное наблюдение и ничего не отправляет в ИИ. Детектор рассчитан на светлую тему из проверенных скриншотов; другие оформления и площадки требуют адаптации.

Монитор ждёт устойчивого изображения и распознаёт изменившуюся позицию. Запросы выполняются последовательно; память кадров сохраняется при паузе и возобновлении анализа. Если сами карты прочитаны не полностью, выполняется до двух дополнительных платных проверок с уточнёнными инструкциями. На одну позицию допускается максимум три попытки в пределах общего лимита. Читаемые карты дают совет сразу, даже если история партии восстановлена не полностью. Принятый неизменившийся кадр больше не оплачивается; при возвращении к нему совет восстанавливается из памяти бесплатно.

Сервер хранит в оперативной памяти ограниченный кеш по отпечатку изображения, провайдеру, модели и ключу. Повтор оплаченной попытки возвращает сохранённый результат, даже при новом идентификаторе подключения. Номер `retryAttempt: 0..2` разрешает ограниченную перепроверку; повторные отправки одного номера бесплатны. Кеш очищается при перезапуске сервера. Счётчик **«Запросов к ИИ»** учитывает отправленные и незавершённые попытки консервативно: отменённый запрос уже мог быть принят провайдером. Ответы из серверного кеша и отказы до обращения к провайдеру исключаются из этого счётчика.

По умолчанию между началами запросов проходит не менее **10 секунд**, лимит подключения окна — **60 запросов**. Интервал и лимит можно изменить перед запуском. После достижения лимита анализ останавливается; пауза и возобновление не обнуляют потраченные запросы этого подключения.

После обновления приложения перезагрузите его вкладку. Запущенный сервер принимает протокол захвата версии **3**; запросы старой вкладки отклоняются до обращения к провайдеру с предложением обновить страницу.

Если экран изменился, пока модель отвечала, устаревшее наблюдение не применяется. Запрос, уже принятый провайдером до паузы или отмены, может быть оплачен по его правилам.

## Настройки API и ключ

Поле **«API-ключ»** находится в **«Настройках ИИ»**. Введённый ключ передаётся локальному серверу для сохранения в `.env`; сервер не возвращает сохранённое значение браузеру. При повторном открытии настроек показывается только наличие ключа. Пустое поле при сохранении оставляет существующий ключ выбранного провайдера.

`.env` исключён из Git и не доступен через HTTP-сервер. Ключ не включается в экспорт позиции и не сохраняется в `localStorage`. Настройки перечитываются перед распознаванием: после сохранения ключа или модели перезапуск сервера не нужен. Для изменения порта сервер нужно перезапустить.

Настройки можно задать и файлом: скопируйте `.env.example` в `.env` и заполните поля локально.

```dotenv
VISION_PROVIDER=genapi
GENAPI_API_KEY=ваш_ключ_GenAPI
GENAPI_MODEL=gpt-6-luna
PORT=8765
```

Для прямого OpenAI API выберите **«OpenAI напрямую»** в настройках или задайте `VISION_PROVIDER=openai`, `OPENAI_API_KEY` и `OPENAI_MODEL`. Модель должна принимать изображения и поддерживать Structured Outputs в Responses API. Ключи двух провайдеров хранятся и используются отдельно.

В GenAPI используется официальный совместимый endpoint `https://proxy.gen-api.ru/v1/chat/completions`: авторизация Bearer, изображение `image_url`, ответ по JSON Schema. Идентификатор `gpt-6-luna`, поддержку изображений и структурированного вывода указывает [страница модели GenAPI](https://gen-api.ru/model/gpt-6-luna). Форматы описаны в [документации GenAPI](https://gen-api.ru/docs/openai-format), адрес подключения — в [общей информации для подключения](https://gen-api.ru/docs/general-information-for-connection). Прямая интеграция OpenAI использует [Responses API с изображениями](https://developers.openai.com/api/docs/guides/images-vision?api-mode=responses) и [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses).

Сам сервер не сохраняет изображения кадров и не ведёт их журнал. Кеш в оперативной памяти содержит отпечатки и результаты распознавания. Предпросмотр остаётся локальным; во время анализа отдельные обрезанные кадры игрового поля передаются провайдеру. Их дальнейшая обработка определяется правилами этого сервиса. В прямом запросе OpenAI дополнительно задаётся `store: false`.

## Память партии и неоднозначные кадры

Автоматический режим отдельно хранит подтверждённую историю и текущую видимую позицию. История обновляется только по строгим согласованным переходам. Для совета по текущему кадру достаточно читаемых карт, козыря и доступного действия: неполная история, скрытый остаток колоды или старое сохранение другой партии больше не блокируют совет. Средняя уверенность модели допустима после локальной проверки карт, уникальности и правил покрытия; низкая требует перечитывания. Самооценка модели не является измеренной точностью.

При пропущенных действиях помощник даёт совет по текущим картам, сохраняя прежнюю подтверждённую память отдельно. Неизвестный отбой и остаток колоды не выдумываются: они показываются как неизвестные, а вероятности скрытых карт временно не вычисляются. Кнопка **«ВСЁ»** означает доступное завершение подкидывания, **«БЕРУ»** — защиту. Предыдущий читаемый кадр помогает определить следующую очередь после пропущенного покрытия и добора. Если сами карты противоречат правилам, выполняются ограниченные перепроверки; затем наблюдение ждёт изменения стола. Ручная проверка остаётся необязательным запасным вариантом.

В профиле **«durak.hlop.de · с компьютером · без перевода»** после взятия карт следующим атакует соперник: на пустом столе помощник показывает ожидание его хода. Переход карт со стола в вашу руку проверяется до определения начального хода по пустому столу; учитываются частичное покрытие, добор и дополнительные подкинутые карты. После успешного отбоя ваша следующая атака остаётся доступной.

На этой площадке покрывать нужно **слева направо**: совет предлагает только первую непокрытую карту, при этом сохраняет подходящие карты для покрытия остальных атак. Распознавание сохраняет визуальный порядок столбцов. Для других игр остаётся общий режим с выбором любой непокрытой атаки.

Начинать наблюдение лучше с раздачи: 6 карт у каждого, **24 карты в колоде**, включая открытый козырь. Пустой стол не обязателен: первый кадр может уже содержать атаку, защиту или перевод в первом заходе. Если видимые руки и стол согласуются с допустимыми ходами из начальных шести карт без добора, взятия и отбоя, остаток **24** определяется автоматически. Например, 6 ваших карт, 5 карт соперника и одна его атака на столе принимаются без ввода счётчика колоды. Кнопка **«БЕРУ»** рядом с непокрытой атакой служит признаком того, что вы защищаетесь.

Когда счётчик колоды не показан, такой первый кадр новой сессии принимается за начало партии. Это предположение: одинаковое расположение карт само по себе не доказывает отсутствие предыдущих заходов. По мере наблюдения остаток считается из сохранённой памяти. Для подключения посреди партии с пропущенным отбоем одного снимка недостаточно, чтобы восстановить точную историю.

Согласованные переходы позволяют запоминать сыгранные карты, покрытый отбой и карты, взятые соперником. Новая раздача после пустой колоды или со сменившимся козырем определяется автоматически после двух согласованных чтений одного стабильного кадра. Перед заменой прежняя позиция сохраняется отдельной архивной записью в локальном хранилище браузера. Кнопка **«Новая партия»** остаётся для явного начала новой памяти.

Проверка умеет восстановить завершённую защиту, даже если кадр с самим покрытием был пропущен: исчезнувшие из вашей руки карты должны законно покрывать все непокрытые атаки, а добор, количество карт и следующая очередь хода — согласовываться с исходом захода. Например, после атаки **6♥** при козыре ♣ исчезновение вашей **10♣**, появление **8♥**, пустой стол и возвращение обеих рук к шести картам дают отбой **6♥ + 10♣**, остаток колоды **22** и вашу следующую атаку. Если те же изменения могут означать перевод или взятие, такое восстановление не применяется без дополнительных признаков.

## Ручной режим — запасной вариант

Вкладка **«Вручную»** открывает отдельную позицию и прекращает автоматические запросы. Ручная партия и наблюдение за окном сохраняются отдельно. Для ручного режима API-ключ не нужен.

Нажмите **«Выбрать свои карты»**, отметьте карты кликами в колоде и нажмите **«Готово»**. Выберите открытый козырь, очередь хода и число карт соперника. Для стола используйте **«Добавить атаку»**, а покрытие выбирайте в слоте справа. Отбой и известные карты соперника также выбираются кликами. Нажмите **«Сохранить и рассчитать»**.

Остаток колоды по умолчанию считается автоматически: `36 − ваша рука − карты стола − отбой − количество карт соперника`. Известные карты соперника входят в его общее количество и повторно не вычитаются. Открытый козырь входит в колоду, пока не добран.

Кнопка **«Я так походил»** переносит свою выбранную карту на стол в сохранённой позиции приложения. После завершения захода укажите его исход: бито, вы взяли или соперник взял; обновите добор и счётчики по экрану. Ввод кодами оставлен в дополнительных настройках: `6C`, `10D`, `QH`, `AS`; масти `C` ♣, `D` ♦, `H` ♥, `S` ♠.

Кнопка **«Использовать эту позицию в автоанализе»** позволяет явно передать проверенную ручную позицию в память наблюдения. Переключение вкладок само по себе позиции не смешивает.

Позиции и черновики сохраняются в `localStorage` браузера. Доступны отмена изменений и импорт/экспорт JSON. При конфликте карт или некорректных счётчиках советы скрываются до исправления.

## Правила выбранной версии

- Два игрока, колода 36 карт. Козырь бьёт любую некозырную карту; карту одной масти бьёт только более старшая карта этой масти.
- Подкидывать можно номиналы, уже присутствующие на столе, включая карты покрытия.
- Лимит атаки зависит от числа карт защитника в начале захода, максимум шесть. Он не уменьшается после каждого покрытия.
- Перевод допустим до начала защиты, когда все карты атаки одного номинала. Добавленная карта должна совпадать по номиналу, а вся атака — помещаться в лимит принимающего игрока и максимум шесть карт.
- По умолчанию перевод разрешён с первого захода. Для площадок с пятью картами в первом заходе или запретом первого перевода измените параметры правил.

Правила площадок могут различаться: [правила Durak](https://www.durak.app/ru/rules/), [переводной Дурак на Мини-играх Mail](https://minigames.mail.ru/info/article/durak_perevodnoy_pravila).

## Что означают проценты и советы

Вероятности считаются при предположении равномерного распределения неизвестных карт между рукой соперника и колодой. Известные карты соперника учитываются отдельно; открытый козырь в колоде исключается из возможной руки соперника.

Для события «есть хотя бы одна подходящая карта» используется гипергеометрическая формула:

```text
P = 1 − C(U − B, k) / C(U, k)
U — неизвестные карты, доступные для руки соперника;
B — подходящие карты среди них;
k — неизвестные места в его руке.
```

Если подходящая карта уже известна в руке соперника, вероятность её наличия равна 100%. Наличие покрытия не означает, что соперник выберет защиту: он может перевести или взять. Вероятность покрытия одной карты не равна вероятности покрыть всю атаку.

Рейтинг ходов — **эвристическая оценка**, учитывающая расход сильных карт и козырей, повторные номиналы и доступные ответы. **Точная вероятность победы не рассчитывается**; лучший рейтинг не доказывает оптимальность хода. Полного поиска дерева партии, модели поведения соперника и обучения на сыгранных партиях пока нет.

## Проверка и ограничения

```powershell
node --test
```

Тесты проверяют правила, вероятности, сохранение памяти, совет без полной истории, переход после пропущенного покрытия, смену козыря, ограниченные повторы, кеш, паузу во время запроса, локальное выделение поля, контракты GenAPI/OpenAI и изоляцию локального HTTP API. Внешние вызовы в автоматических тестах заменены имитацией ответов.

На предыдущем этапе выполнен реальный запрос GenAPI / `gpt-6-luna` на присланном скриншоте первого хода. Модель правильно прочитала шесть карт руки, пять карт соперника, атаку **6♥**, открытый козырь **A♣** и роль защиты с высокой уверенностью; скрытый счётчик колоды оставила неизвестным. Проверка состояния автоматически получила остаток **24**, приняла позицию и выдала совет покрыть **6♥** картой **10♣**. Ручное уточнение для этого кадра не потребовалось.

В текущем исправлении выполнены настоящие запросы GenAPI / `gpt-6-luna` и проверено отображение в браузере на предоставленных кадрах. Последний скриншот: рука **8♦ 9♥ A♣ 10♠ Q♠**, стол **6♣ → K♣**, козырь **7♠**, совет **нажать «ВСЁ»**. Последовательность прежних кадров: **покрыть 6♥ картой 10♣ → после отбоя атаковать 7♠**. Переключение кадров не требует ввода карт вручную; повторный разбор уже проверенного изображения подтвердил бесплатный ответ из серверного кеша. Это проверка последовательности снимков и общего пути распознавания; непрерывная живая партия через браузерный диалог захвата целиком пока не пройдена.

В интерфейсе доступен дополнительный пункт **«Проверить снимок игры»**: выбранное изображение проходит тот же поиск стола, API и автоматический расчёт совета. Основной источник остаётся демонстрацией окна.

Демонстрация экрана зависит от браузера и требует подтверждения в его системном диалоге. Перекрытые карты, анимации и пропущенные ходы могут мешать распознаванию. При неоднозначном наблюдении память сохраняется до согласованного изменения карт; ручной режим доступен, если нужно исправить память партии.
